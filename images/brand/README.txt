Annora logo kit v1

Files:
- annora-icon.svg: icon only, transparent background.
- annora-app-icon.svg: app-style rounded icon, 1024x1024 viewBox.
- annora-horizontal.svg: icon + wordmark + tagline for light backgrounds.
- annora-horizontal-dark-bg.svg: logo lockup on dark background.
- annora-icon-monochrome.svg: single-color icon for special use.

Primary colors:
- Navy: #071B33
- Coral: #FF5A3D
- Orange: #FF7A1A
- White: #FFFFFF

Recommended usage:
- Use annora-icon.svg for favicon/PWA/app/profile image.
- Use annora-horizontal.svg for website header.
- Use annora-horizontal-dark-bg.svg in presentations or dark sections.
