Om Annora

Et tydeligt lokalt samlingspunkt

Annora er skabt med fokus på enkelhed, nærhed og overskuelighed. Navn og visuel identitet skal signalere retning, klarhed og tillid.

Målet er at gøre det lettere at opdage muligheder tæt på dig – og lettere at dele noget, andre lokalt kan få glæde af.

  • Lokalt fokus frem for global støj
  • Enkel oprettelse og tydelig navigation
  • Designet til både mobil og desktop
